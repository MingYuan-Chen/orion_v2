v2.2.0 (2026/01/22)

Changes:
  New Feature:
    - Stability test
      - A new button "Stability Test" display in Main view (Only Athena platform support)
      - A new view for Stability test can setup test items and run tests
      - Setup ping test for ethernet and wifi
      - Save and load all configs as json file
      - Save all test result as log file
  Update:
    - Function Test Item:
      - SD Card R/W: new add storage R/W test item
      - Power Button Event: new add power button test item
        - Use "stdbuf -oL hexdump -v /dev/input/event0" to receive event
        - Test Button press and release
      - Camera Event: new add camera event test item
        - Use "stdbuf -oL hexdump -v /dev/input/event0" to receive event
        - Test "Right" and "Left" Button press and release
      - Camera Preview: Use correct command to display camera preview window
        - Use "modetest -M xlnx -w 41:alpha:0" to display camera preview window then start test
        - Use "modetest -M xlnx -w 41:alpha:255" to hide camera preview window after test
      - HDMI Mirror Display: Merge event receiving test as one test item
        - Use "stdbuf -oL hexdump -v /dev/input/event0" to receive event
        - Test HDMI connect and disconnect

6. Note:
- Installation:  
  - Please ensure "dqa_package" folder copied to root directory of any of USB flash drive and plug in target device before launch tool.
    - There is "dqa_package" folder exist after download and extract the zip file.
- Peripheral Device Connection:
  - 2 × USB-A drives
  - 1 x Micro SD card
  - HDMI cable connect to display monitor
  - 1 x camera connector with Left and Right button
  - 4 x camera modules (LVDS, LVDS Smart Cable, MIPI VGA, Scorpius)
  - 1 x AC adapter
- Test Operation:
  - [Touch 9 Points] Please ensure tool closed by tap "Close" button before you click "Pass/Fail" button
  - [Touch Drag Draw] Please ensure tool closed by tap "Quit" button before you click "Pass/Fail" button
